# LOVE QUEST — Game Design

## Objetivo
O produto é uma mensagem romântica interativa com elementos de jogo, não um jogo de habilidade. Duração-alvo: 1–3 minutos.

## Regras de design
- Cada cena deve ter um objetivo evidente e exigir no máximo uma interação simples.
- Não usar vidas, game over, punições, puzzles difíceis ou cronômetros que pressionem o jogador.
- Cada minigame deve durar 10–30 segundos e ser impossível de falhar permanentemente.
- As escolhas negativas são uma piada visual/narrativa, não uma barreira real.
- Após uma tentativa de escolha negativa, exibir uma resposta engraçada e oferecer imediatamente um caminho claro para continuar.
- A mensagem final deve sempre ser alcançável em poucos passos.
- Dar feedback visual e textual a cada interação.
- Usar humor carinhoso, absurdo e não constrangedor.

## Estrutura recomendada
1. Entrada com nome da pessoa e nome do remetente.
2. Tutorial rápido de coleta de corações.
3. Escolha negativa que dispara uma piada.
4. Teste de compatibilidade absurdo e curto.
5. Revelação final personalizada.

## Checklist
- A pessoa entende o que fazer sem instruções longas?
- Alguma interação pode bloquear o progresso? Se sim, simplificar.
- É possível jogar só com toque?
- A mensagem é o ponto alto?
- O humor continua simpático mesmo na repetição?
